# Anatomy reference study

This file records research context. It is not a normative SDK contract.

## What Anatomy demonstrates

Anatomy combines a concise agent workflow, reusable drawing kit, focused references, examples, evaluation, and visual checks. It produces detailed isometric explanatory figures from ordinary JavaScript and SVG.

## Ideas Incantly adopts

- Plan the teaching idea and parts before drawing.
- Keep a short always-loaded rule set and retrieve only relevant references.
- Use one model to drive geometry and displayed values.
- Build static geometry once and move it with transforms.
- Use a restrained tone hierarchy and one visual accent.
- Treat verification, examples, and evaluation as part of the product.
- Turn repeated generated patterns into reusable kit functions.

## Ideas Incantly does not adopt

- Invented machines standing in for the real phenomenon.
- Figures with dozens or hundreds of decorative parts.
- Multi-hour generation and visual review loops.
- A Node build step at learner request time.
- Trusting a developer to manually review every generated result.
- Adopting Anatomy as a runtime dependency.

## Product difference

Incantly must generate in seconds, run on learner devices, survive untrusted input, persist inside notes, and expose formulas and parameters for exploration. Anatomy remains useful research for craft and reusable geometry, but Incantly's central problem is reliable teaching interaction.
