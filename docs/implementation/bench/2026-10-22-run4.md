# Generation bench

48 generations: 24 launch requests (PRD 17.8) in 2 conditions. Plans on haiku, scenes and repairs on sonnet, effort low, each call one subagent.
Times are what a learner waits for, on the pipeline's own clock: each model call's time plus this machine's validation and probe. Calls are cut off at the deadline as the service would cut them.
Subagents think before some replies; the service calls models with thinking off, so each call counts from its start to the end of its reply less the time spent thinking. The last section gives the times as measured, thinking included.

## Subagent overhead

Each call ran as a subagent, which adds its own fixed cost (its harness prompt and turn) to what an API call would take. Measured with one-word replies:

- claude-haiku-5-5: 1.0 s per call (median)
- claude-sonnet-5-5: 1.3 s per call (median)

Subtracting it from every call (2 models), the totals above become an estimate of the API path:

| --- | --- | --- |
| library | 0.9 / 1.6 / 2.6 / 0.8 | 100% |
| novel | 12.7 / 15.7 / 15.8 / 12.1 | 100% |
